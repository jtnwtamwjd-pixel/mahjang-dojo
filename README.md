# 麻雀点数道場

麻雀の点数計算を、遊びながら覚えるためのWebアプリです。ファイルは `index.html` 1つだけで、外部のライブラリは使っていません。

- **対局モード**：CPU3人（強さは3段階）と東風戦を打ちます。誰かがアガるたびに、その手の翻・符・点数が問題として出ます。各局のあとには、あなたの打牌を1手ずつ牌効率（向聴数と受け入れ枚数）で採点します。
- **ドリル**：点数表（全6レベル）、符計算、翻数、実戦の4種類があります。
- **学ぶ**：点数の仕組み、符の数え方、役一覧、早見表をまとめています。

スマホを横向きにして遊ぶのがおすすめです。

## 監督キャリア

サッカークラブの監督になって、架空のクラブでリーグを戦うマネージャーゲーム。GitHub Pages では `/soccer/` で開けます。日本と海外5カ国（イングランド・スペイン・ドイツ・イタリア・フランス）の6リーグ（各12クラブ）から好きなクラブを選べ、各国上位クラブが集まる国際大会もあります。日本リーグには外国籍選手の登録枠（5人）があります。作戦・選手交代・移籍（レンタル含む）・育成（若手の覚醒イベント）・ユースアカデミー（施設強化・スカウト・トップ昇格）・カップ戦・理事会の評価があり、フォーメーションとメンバーは5つまで保存できます。進行はブラウザに自動保存され、以前のセーブもそのまま引き継げます。

## 全固体への道 〜O西 5ねん戦記〜

ファミコン風の電池開発育成シミュレーション。GitHub Pages では `/battery/` で開けます。プロジェクトリーダー O西 になって、5年（240週）のうちにプロト量産試作をクリアするとゲームクリアです。固体電解質・高Ni正極・シリコン負極・セル試作は最初から同時並行で進み、3年目からプロト量産試作が解放されます。報告会のとき生技部との連携が30以上だと設備導入テーマが解放され、目標をクリアした材料で特性検証に合格し、3000万円で設備を導入しないとプロト量産試作はできません。予算で派遣社員（半年）を雇ったり、外部に実験を依頼（納期2週）したりできます。資料作成週はストレスが20たまり、K口役員に呼ばれた直後の週は休めません。O西の下で室長 E口が室を指揮し、室のメンバー12人（得意分野がそれぞれ違う）を各テーマに配置して、複数のテーマを同時に進めます。テーマの優先度は自分で決められますが、K口役員に指示されたテーマは必ず最優先になります。毎週、実験・計算・勉強（4択・○×・計算問題）・学会・特許・予算申請・チームケア・E口室長との相談・休養から行動を選びます。K口役員に「オウイ」と呼ばれたときに話すと好感度が上がり予算や人員が増えますが、ストレスもたまります。ストレスが高いと部下に当たってモチベが下がり実験ミスが増え、企画部・生技部・調達部・社外とのやりとりの結果も悪くなります。月末の社内報告会（前週は資料作成で実験1水準まで）もあります。部下を管理する E口室長との関係が悪いと、部下が転職してしまいます。半年ごとにキャリア入社が1人、毎年4月に新人が1人入ります。新人は1年間戦力にならず、指導役の部下の工数が半分になります。進行はブラウザに自動保存されます。
