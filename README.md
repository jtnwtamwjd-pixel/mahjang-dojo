# 麻雀点数道場

麻雀の点数計算を、遊びながら覚えるためのWebアプリです。ファイルは `index.html` 1つだけで、外部のライブラリは使っていません。

- **対局モード**：CPU3人と東風戦を打ちます。誰かがアガるたびに、その手の翻・符・点数が問題として出ます。
- **ドリル**：点数表（全6レベル）、符計算、翻数、実戦の4種類があります。
- **学ぶ**：点数の仕組み、符の数え方、役一覧、早見表をまとめています。

スマホを横向きにして遊ぶのがおすすめです。

## 監督キャリア

サッカークラブの監督になって、架空の12クラブのリーグを戦うマネージャーゲーム。GitHub Pages では `/soccer/` で開けます。作戦・選手交代・移籍・育成・理事会の評価があり、進行はブラウザに自動保存されます。
